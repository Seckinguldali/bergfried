# Bergfried — Fleet Tracking System

## What is this?

Bergfried tracks vehicles and equipment in real-time. Devices (phones, trackers) send location and data to a central server, which stores and displays the information.

## How it works

1. Devices send location and data to the server.
2. The server saves this data.
3. Users can view the data and history.

## What you need

- A computer (server) with Linux or Windows
- Python 3.8 or newer
- The Bergfried code (from GitHub)

## Quick start

For setup instructions, see [user_manual.md](user_manual.md).

## What's inside

- `server/ingestion-api/` — the central server that receives data
- `data/` — where data is stored
- `docs/` — documentation

## Future features

- Dashboard to view vehicle locations on a map
- Alerts when something goes wrong
- Reports and history
- Cloud backup (later)
